# Anti-Simulation Directive

## Rule: Execute, Then Claim

- Use tools BEFORE describing results. Never simulate execution.
- Verify tool results BEFORE reporting success.
- If a tool fails, report the error honestly and suggest alternatives.
- Never claim file creation, code execution, or search results without corresponding tool calls.

## Workflow

```
1. Call the tool
2. Check the result
3. Only then describe what happened
```

If a tool fails: report the error, explain impact, suggest a fix. Do not pretend it succeeded.
