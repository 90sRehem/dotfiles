# Progress Reporting Template

## 📋 **Standard Progress Report Format**

All subagents should use this format to provide visibility into their work:

### **1. Initial Plan**
```
🎯 **TASK OVERVIEW**
- Objective: [What I'm building/doing]
- Approach: [High-level strategy]
- Files to create/modify: [List of files]
- Estimated steps: [Number of major steps]
```

### **2. Step-by-Step Execution**
```
🔄 **STEP X/Y: [Step Description]**
- Action: [What I'm doing now]
- Files: [Specific files being worked on]
- Purpose: [Why this step is needed]
- Progress: [What's been completed]
```

### **3. File Creation Reports**
```
📁 **CREATING: [filename]**
- Purpose: [What this file does]
- Key components: [Main sections/functions]
- Dependencies: [What it depends on]
- Next: [What comes after this]
```

### **4. Completion Reports**
```
✅ **COMPLETED: [Step/File/Feature]**
- What was built: [Summary]
- Key features: [Main functionality]
- Files created: [List with purposes]
- Next steps: [What should happen next]
```

### **5. Error Handling**
```
⚠️ **ISSUE ENCOUNTERED: [Problem]**
- What happened: [Description]
- Impact: [How it affects the task]
- Solution: [How I'm fixing it]
- Status: [Current state]
```

### **6. Final Summary**
```
🎉 **TASK COMPLETE**
- Delivered: [What was built]
- Files: [Complete list of files created/modified]
- Features: [Key functionality implemented]
- Testing: [How to verify it works]
- Next: [Suggested next steps]
```

## 🎨 **Example Usage**

```
🎯 **TASK OVERVIEW**
- Objective: Creating a Snake game in JavaScript
- Approach: HTML5 Canvas with game loop pattern
- Files to create: index.html, style.css, snake.js, food.js, game.js
- Estimated steps: 5 major steps

🔄 **STEP 1/5: Project Structure Setup**
- Action: Creating basic HTML structure
- Files: index.html
- Purpose: Foundation for the game
- Progress: Setting up canvas and basic layout

📁 **CREATING: index.html**
- Purpose: Main HTML file with canvas element
- Key components: Canvas element, CSS links, JS imports
- Dependencies: None (base file)
- Next: CSS styling setup
```

## 🔧 **Implementation Notes**

- Use emojis for visual clarity
- Keep updates concise but informative
- Report both successes and failures
- Always explain the "why" behind actions
- Update progress regularly during long tasks
